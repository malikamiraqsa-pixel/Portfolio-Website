# Zara Malik Portfolio

A responsive personal portfolio website for Zara Malik built with Next.js and Tailwind CSS.

## Local development

1. Install dependencies:
   npm install
2. Run the dev server:
   npm run dev
3. Open http://localhost:3000

## Editing content

Update the text, project details, links, and contact information in `app/page.tsx`.

## Deploying

This project is ready to deploy on Vercel, or you can export a static site and host it on GitHub Pages with a build step adjustment if needed.

## Metadata and social preview

Open Graph and page metadata are defined in `app/layout.tsx`.
